Mes parcours

    Dans OsmAnd

    1. « Naviguer » puis « Dans OsmAnd » (ou « Ouvrir dans OsmAnd »), et choisis OsmAnd dans le menu de partage. La première fois, OsmAnd peut se trouver sous « Plus ».
    2. Dans OsmAnd, ouvre la trace importée puis Suivre la trace. Les consignes de virage calculées par Piste sont incluses.
    3. Laisse « Attacher aux routes » désactivé pour suivre exactement le tracé. OsmAnd guide écran verrouillé et sur CarPlay.
    4. Pour les recalculs hors trace, utilise le profil Moto avec « Préférer les routes non revêtues ».

    Le calcul exclut les voies marquées interdites aux motos dans OpenStreetMap ainsi que les sentiers, pistes cyclables et chemins piétons ou cavaliers.
