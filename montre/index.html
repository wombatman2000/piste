    Réglages GitHub

    À faire une seule fois. La page a besoin d'une clé d'accès qui ne permet d'écrire que dans ton dépôt piste.

    1. Sur github.com : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Nom : Sillage. Expiration : la plus longue proposée.
    3. Repository access → Only select repositories → piste.
    4. Permissions → Contents → Read and write.
    5. Generate token, puis copie la clé et colle-la ci-dessous.

    La clé reste uniquement sur cet iPhone.
